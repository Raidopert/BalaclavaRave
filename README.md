# 🎸 BALACLAVA RAVE

Ритм-игра в стиле лондонского андеграунда: неон, балаклава и барабанные мелодии.
Один самодостаточный HTML-файл — синтез музыки прямо в браузере (Web Audio), без ассетов и серверов.

**Играть:** https://raidopert.github.io/BalaclavaRave/

## Управление

| Дорожка | Клавиатура | Геймпад | Сенсор |
|---|---|---|---|
| БАС | D | стрелка ← / LB | тап по кнопке |
| КИК | F | стрелка ↓ | тап |
| НОТА | J | стрелка ↑ | тап |
| ДРАМ | K | стрелка → / RB / X | тап |

Клавиши переназначаются в «⚙ НАСТРОЙКИ УПРАВЛЕНИЯ». Пауза: ESC / P / START.

## Сложности (на каждом треке)

- **ЛЁГКИЙ** — мелодия прорежена (шаг egap), медленный подлёт
- **СРЕДНИЙ** — тема как написана
- **СЛОЖНЫЙ** — тема + восьмые на басу, перебивки, полные барабаны

Спец-секции в каждом треке: 🐍 ЗМЕЙКА, 🌊 ВОЛНА, ⚡ РАЗБЕГ, 🌀 ПИЛКА, 💧 КАСКАД (2–3 кнопки разом),
⚡ ПЕРЕБИВКА (барабанный сбой), 🎹 СОЛО-РУЛЛ, 🔥 ОГНЕННОЕ СОЛО. Лесенки «поют» тоны мелодии трека.

## Установка на телефон (PWA)

Открой сайт в Chrome/Safari → «Добавить на главный экран» / «Установить приложение».
Игра ставится как приложение: свой значок, полный экран, офлайн (service worker кэширует всё).

## Редактор треков

Кнопка «🎛 РЕДАКТОР ТРЕКОВ» в меню. Вставь JSON одного трека или массива →
**▶ ПРОГНАТЬ** (тест в игре), **💾 ДОБАВИТЬ** (трек появится в списке с меткой «СВОЙ»),
**📥 ЗАМЕНИТЬ ВСЁ**, **📄 В ТЕКСТ** (экспорт для бэкапа/переноса). Свои треки хранятся в localStorage браузера.

Формат трека:

```json
{
  "name": "МОЙ ТРЕК",
  "bpm": 130,
  "loopBeats": 16,
  "stars": 3,
  "bassKind": "saw",
  "leadKind": "lead",
  "egap": 1.5,
  "mel": [[0,1,69],[1,1,72],[2,1,74],[3,1,76]],
  "chords": [[0,4,45,[57,60,64]],[4,4,41,[53,57,60]]],
  "drum": {"k":[0,1,2,3],"s":[1,3]}
}
```

- `mel` — мелодия: `[доля, длина, midi]` (в долях от начала круга; midi 69 = ля 440 Гц)
- `chords` — гармония: `[доля, длина, бас-midi, [ноты аккорда]]`; повторяется каждый круг
- `drum` — `k`: доли бочки, `s`: доли малого/клэпа (внутри такта 4/4)
- `loopBeats` — длина круга; мелодия должна помещаться в него
- `bassKind` — `saw | square | sub | acid | reese`; `leadKind` — `lead | chip` (8-битный квадрат)
- `egap` — минимальный шаг нот на ЛЁГКОМ (в долях; 2 = четверти, 0.5 = все восьмые)
- `stars` — 1..5, сложность для карточки

## Деплой

GitHub Pages отдаёт ветку `main`: `index.html` (копия `download/balaclava-rave.html`),
`manifest.json`, `sw.js`, иконки. После правки игры не забудь обновить копию:

```bash
cp download/balaclava-rave.html index.html
```
